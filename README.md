# Aeroguard-UAV-Health-Monitoring-System
AeroGuard – UAV Health Monitoring System

AeroGuard is an STM32-based UAV Health Monitoring System focused on improving drone safety and reliability.

The project aims to monitor important UAV health parameters, identify abnormal operating conditions, and help prevent potential system failures.

Technology: STM32 Microcontroller, Embedded C, Sensors and UAV Systems.

Goal: To develop a reliable and intelligent UAV health monitoring solution.
